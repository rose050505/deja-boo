## Fixes
1. **Move and grace filters** (src/miner/move-filter.ts:35, grace-filter.ts) compare a deleted block with the union of the commit's added ≥4-line blocks by Jaccard, so reformats and moves survive as tombstones (express 347aa56a: Jaccard 0.04 / containment 0.88; requests ef8563ab: 0.08 / 1.00; httpie 05db75bd: 0.00 / 1.00 because the replacement is 3 lines and is not a block). Use containment instead: drop the deletion if ≥0.9 of its fingerprint is contained in **all** lines added by the commit (any size) or in the post-commit content of the touched files.
2. **Revival needs the code to have actually been dead.** In scanForRevivals, skip a candidate when the revival commit's parent tree still contains ≥0.8 of the tombstone fingerprint (in any file), or when the same commit deletes a block matching it ≥0.9 (a move).
3. **Revival match by containment/window, not whole-block Jaccard ≥0.9.** Use the same windowed matching as `check` (window = tombstone line count) or containment ≥0.9 of the tombstone in the added lines, together with fix 2.
4. **Ancestry and duplicates.** Record a revival only if `git merge-base --is-ancestor <death> <revival>`. Collapse duplicates: one revival per (tombstone, patch-id) and per event.
5. **Agent-style rewrites.** Add an auxiliary identifier-normalized fingerprint (rename every identifier to a placeholder before k-gramming, like `renameIds` in the tests) and report max(raw, normalized − small penalty) so multi-identifier renames score. Re-run research §1 with a new mutation row "rename 2–4 identifiers" and "reorder statements", and show the false-alarm rate against unrelated tombstones for the new score (it must stay ≤ 0.1%). Ordinary unrelated edits must stay at zero alarms.
6. **Comment stripping inside strings.** The comment remover treats `/*` inside strings as a comment start for every language (flask `.github/workflows/tests.yaml`: `'docs/**'` turned a 64-line tombstone into 4 hashes, matching unrelated YAML at 1.0). Apply comment syntax per language (YAML/Python/shell: `#` only; JS/TS/C-like: `//`, `/* */`) and skip quoted strings.
7. Small: CLI help says `--grace-days` default 5, the code uses 7 (types.ts) — make them agree. The web stats strip counts 50 revivals but the list omits 13 revivals of aliveAtHead tombstones — make the counts consistent.
